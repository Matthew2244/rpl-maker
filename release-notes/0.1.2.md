Fixes, mostly for Windows and for plug-ins kept somewhere unusual.

- On Windows, a run never finished. The report couldn't be written there, so the window stayed busy and the end was never said. Fixed.
- The checking copy of REAPER now looks for plug-ins in the same folders your REAPER does, so plug-ins on another drive or in a folder you added can be checked.
- It also knows about plug-ins you've installed since it was made.
- Library file names no longer use characters Windows can't save, like a question mark or quotes.
- The report counts libraries and plug-ins separately, so a plug-in split into several libraries reads right.
- If the report can't be saved, the end of the run is still said, with the reason.
- Checking or unchecking a plug-in now says just how many are checked.
- Look for Presets Again during a run, and Open Report before there is one, now say why nothing happened.
- On Windows, messages no longer talk about the Mac or macOS.
