You choose about folder access now.

- On a Mac, the first time you make libraries, Magpie asks once whether to let macOS ask about your folders and drives now. Some plug-ins look there as they load, and checking stops until someone answers macOS. Allow Folder Access Now gets those questions out of the way, then makes your libraries. Not Now just starts. Escape is Not Now. It's never asked again, and File, Allow Folder Access is still there any time.
- If checking waits on a plug-in, what's said now points to File, Allow Folder Access.
- On Windows, libraries are saved in your real Documents folder, even when OneDrive has moved it. Presets kept in VST3 Presets there are found too.
- In Settings, Remove Folder says what it removed, or why it couldn't.
