Settings is now Preferences, on REAPER's key. Magpie notices plug-ins you've already put into REAPER. And on Windows, the hidden copy of REAPER no longer stops to ask about an audio device.

- Settings is now called Preferences. It opens with Command-P on a Mac and Control+P on Windows, the same key as REAPER's own Preferences. Command-Comma and Control+Comma still open it too.
- Say Progress has moved to OSARA's Report selection key: Command-Shift-Space on a Mac, Control+Shift+Space on Windows. These are the keys OSARA's own keymaps use on each system.
- If you've already put a plug-in's presets into REAPER, by hand or by importing a library, its row now starts "Already in REAPER". It's left unchecked, and Check All Shown skips it. You can still check it with Space and make it anyway. The details say what REAPER already has.
- How Magpie tells: it reads the plug-in's own file in REAPER's presets folder, for its VST3, VST2, AU or CLAP version. Almost every plug-in gets one of those as soon as it's used, often holding only a default entry, so that alone doesn't count. A plug-in counts only when its file holds at least half of the preset names Magpie found for it, and at least 3 of them. Entries named Default, Init, Untitled or Program 1, and ones with no name, never count. Names are compared ignoring capitals, spaces and punctuation, so it can be fooled by presets that share names with the maker's but hold something else. It reads REAPER's usual folder only, not a portable REAPER's. REAPER's files are only read, never changed.
- Windows: the hidden copy of REAPER that checks presets stopped at REAPER's first-run question, "You have not yet selected an audio device", in a window that didn't take the focus. Now it uses REAPER's Dummy Audio device, which opens no sound device at all, so the question never comes up. On a Mac it already used a quiet output device.
- Windows: the copy's own windows are hidden as soon as they appear and kept hidden for as long as it runs. REAPER still puts its main window up for about a quarter of a second as it starts, before it can be hidden; it never takes the focus. If the copy ever stops to ask something else, Magpie now says what the question was.
- Both systems: the copy now reads the line in your REAPER's settings that records you accepted REAPER's licence agreement, so a fresh copy can't stop there either.
