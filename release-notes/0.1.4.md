Windows gets folder access too, like the Mac.

- The first time you make libraries on Windows, Magpie asks once whether to check folder access. Check Folder Access Now reads every preset folder and saves a test file where libraries go, then makes your libraries. Not Now just starts. Escape is Not Now. It's never asked again.
- File, Check Folder Access does the same any time.
- If a folder can't be read, it's named, with what to check.
- If Windows Security's ransomware protection stops Magpie saving in Documents, Magpie says so and gives the steps to allow it, or you can choose another folder.
- The same steps are given if a run can't save libraries for that reason.
