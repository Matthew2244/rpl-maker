Windows gets what the Mac has. Matthew asked that both versions be the same, so this release closes the gaps.

- The first time you make libraries on Windows, Magpie asks once whether to check folder access. Check Folder Access Now reads every preset folder and saves a test file where libraries go, then makes your libraries. Not Now just starts. Escape is Not Now. It's never asked again.
- File, Check Folder Access does the same any time. It names any folder it can't read.
- If Windows Security's ransomware protection stops Magpie saving in Documents, Magpie says so and gives the steps to allow it. You can also choose another folder. A run that can't save for that reason gives the same steps.
- NVDA, JAWS and Narrator now hear whether each plug-in in the list is checked. Before, they heard the name but not the check.
- Every control's help tag is now read on Windows too, after its name, the way VoiceOver offers it on a Mac.
- The list, Find, Details and the progress bar now have their own names on Windows, instead of the text that happens to sit before them.
- The hidden copy of REAPER that checks presets no longer shows in the taskbar or Alt-Tab on Windows, so it can't be mistaken for your REAPER. On the Mac it was already out of the Dock.
