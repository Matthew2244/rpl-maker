The first release. Magpie is a working name.

Magpie makes REAPER preset libraries from the factory presets your plug-ins installed. Every preset is loaded by name in a separate, hidden copy of REAPER, and only the ones the plug-in saves back the same are kept. Your own REAPER isn't changed.

- Reads VST3 presets, NKS presets, VST2 preset files, Audio Unit presets and XML presets.
- Big preset sets can be split into one library per folder.
- A report says what was made, what was left out and why.
- Works with VoiceOver on the Mac, and NVDA, JAWS and Narrator on Windows.
- Tells you about updates once, without a window popping up.

Mac: Apple silicon, macOS 12 or later. Windows: 64-bit; the installer isn't code signed yet, so SmartScreen may warn. The Windows version hasn't been tried with a screen reader or a real REAPER yet. Please report what you find.
