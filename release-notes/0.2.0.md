Presets stay organized. REAPER shows a plug-in's presets as one list with no folders, so Magpie now starts each preset's name with its maker's category, and saves libraries in a folder for each plug-in. It can also organize libraries you already have.

- Preset names start with their category, so each category sits together in REAPER's list: "Bass - Deep Sub" next to "Bass - Round", away from "Lead - Saw". This is on at first; Preferences, Start preset names with their category, turns it off.
- Categories come only from the plug-in's maker: the folders its presets were installed in, or the category written inside the preset file. Native Instruments NKS presets carry one, so plug-ins like bx_oberhausen and Knifonium now come out grouped as Bass, Synth Lead, Pads and so on. Magpie never guesses a category from the words in a name. Presets without one keep their name, and a name that already starts with its category isn't given it twice.
- Libraries now go in a folder for each maker, then a folder for each plug-in, such as Plugin Alliance, then bx_glue. Preferences, Folders for libraries, can keep them in the maker's folder only, as before.
- New: Preferences, One library per category. Each category gets its own file, so you can import only the ones you want. It's off at first. Big sets of more than 300 presets are split this way anyway, by category as well as by folder, unless you turn that off.
- New: File, Organize Existing Libraries (Command-Shift-O on a Mac, Control+Shift+O on Windows). Choose a folder of .RPL files, yours or ones from the Hoard, and Magpie makes an organized copy beside it, named the same with (organized) at the end. The folder you chose isn't changed. Names get their categories when the plug-in and its preset files are on your computer. Renaming changes only the name; the settings each preset holds are copied byte for byte. When it's done, Magpie says how many libraries were organized and how many names changed, and Open Report has the details.
- File and folder names now also avoid names Windows keeps for itself, like CON and NUL, and stay short enough that a copy in someone's Downloads folder on a PC still opens.
- Help, How Presets Are Organized explains all of this in the app.
- The first time this version looks for presets, it reads every preset file again, once, to find their categories. After that it's as quick as before.
